# Alinhamento com a RNDS

Este é um laboratório independente de referência para FHIR R4, qualidade de
dados e indicadores públicos agregados. A RNDS é a infraestrutura nacional de
interoperabilidade em saúde; ela não é uma base pública de registros clínicos
para uso em portfólio.

O projeto não possui integração, acesso assistencial, homologação, certificação
ou autorização do Ministério da Saúde/DATASUS. Não use os termos “integrado à
RNDS”, “homologado” ou “certificado” para descrevê-lo.

O desenho técnico alinha-se conceitualmente ao uso de contratos, bundles,
rastreabilidade, validação e interoperabilidade. Uma integração real seria
institucional: desenvolvimento no ambiente de homologação, solicitação de
acesso e apresentação de evidências para eventual produção. Nada neste
repositório substitui esses processos.

Referências: [página institucional da RNDS](https://www.gov.br/saude/pt-br/composicao/seidigi/rnds),
